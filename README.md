# Student Attendance System (QR Code Enabled)

A simple and efficient attendance management system developed using **JSP**, **Servlets**, and **MySQL**.  
The application allows students to mark their attendance by scanning a QR/Barcode, while administrators can manage student records and review daily logs through an intuitive web interface.

---

## 📌 Key Features

### 🧾 Student Enrollment  
Add new students with unique details while preventing duplicate registrations.

### 📚 Database Connectivity  
All data — student information and attendance logs — is stored securely using **MySQL**.

### 📷 QR/Barcode Attendance  
Attendance is recorded by scanning a QR or barcode assigned to each student.  
The system intelligently prevents multiple entries for the same day.

### 📊 Attendance Logs  
View complete attendance history including:  
- Student ID  
- Name  
- Date & time  

### 🎨 Responsive Interface  
Clean and modern UI built with custom CSS for smooth and user-friendly navigation.

---

## 📁 File Overview

| File Name          | Description |
|--------------------|-------------|
| **addStudent.jsp**     | Form to add/register new students. |
| **markAttendance.jsp** | Scans QR/Barcode and marks attendance. |
| **viewRecords.jsp**    | Displays complete attendance history. |
| **database.jsp**       | Handles MySQL database connection settings. |
| **styles.css**         | Dark-mode UI styling and layout. |
